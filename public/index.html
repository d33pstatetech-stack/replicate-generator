 How validation works

        
    
          
  •  Schema is source of truth: every input shown comes from Input object
    • 
          
  •  Enums become dropdowns — you cannot pick 4K if max enum is 1080p
    • 
          
  •  Min/max clamp sliders & numbers — e.g. width 256–1440, lora_scale -1 to 3
    • 
          
  •  Conditional params: width/height only when aspect_ratio=custom and not go_fast
    • 
          
  •  File URIs: drag & drop or paste URL; local files auto-convert to data: URIs for correctness
    • 
          
  •  Unknown params hidden — no stale fields from other models
    •
