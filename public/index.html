Curated LoRAs — HF + Replicate

HF + Replicate

Public community adapters — quick copy repo or .safetensors URL for extra_lora / lora_weights. No HF token entry needed in LoRA box — Private repos are auto-proxied via Worker using HUGGINGFACE_API_KEY when the repo is on HF_PROXY_REPO_ALLOWLIST.

Replicate LoRA quirk — read before Filling
Bare owner/repo is misread as a Replicate model (loader fetches replicate.com/…/_weights → 404) and any other non-matching URL gets downloaded as a tarball → unable to unpack tarball / Failed to download tarball. Always use one of the three labeled formats below: huggingface.co/owner/repo (prefix required), direct /resolve/main/*.safetensors file URL (required when a repo holds 2+ .safetensors files), or the .tar from the training output page (always works). For future trainings, grab the flux-lora.tar download link from the output page.
Tip: Select a model that accepts LoRA (e.g. fofr/flux-pixar-cars → extra_lora, wavespeedai/wan-2.1-t2v-480p → lora_weights) then click Fill to auto-fill.
